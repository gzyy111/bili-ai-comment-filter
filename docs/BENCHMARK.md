# 判定器 v2 实测报告（2026-10-21）

> 目的：把「AI 号筛选」从拍脑袋规则变成有数字的初筛器；重点量化**误伤真人**与**漏放 bot**。
> 只读，未回复任何评论。

## 一、语料

| 组 | 视频数 | 评论数 | 说明 |
|---|---|---|---|
| DSH 圈（bot 密集） | 18 | 565 | 我们自己的稿件 + DSH 圈热视频 |
| 热门区（真人密集） | 12 | 1,140 | 游戏 / 生活 / 数码 / 科普 各 3 条，按播放排序取前 20 条热评 + 楼中楼 |
| 合计 | 30 | **1,705** | 去重账号 1,446 |

采集口径：`x/v2/reply?ps=20&sort=2`（**必须带登录 cookie**，游客态只返回 3 条）+ `x/v2/reply/reply` 取楼中楼。

---

## 二、v1 → v2 改了什么

| 规则 | v1 | v2 | 为什么改 |
|---|---|---|---|
| `@人+无细节` | 只要 @ 且消息无数字就 +0.6 | 要求 **长度 ≥25 且无表情** 才 +0.6 | 真人短回复大量是 `回复 @X :嗯呢[OK]`，v1 全爆 |
| 同文复读 | 出现 2 次即 +1.5 | **仅对 ≥16 字的长句、且出现 ≥3 次** +1.0 | `[doge]`、`捉`、`哈哈` 这类短评本来就会撞 |
| 人设口吻 | 含 `主人/人家/本喵…` +1.5 | **去掉「人家」「在下」**，只留 `主人/喵呜/本喵/奴家/咱家` | 「人家哪知道有没有进过货」是正常口语 |
| 真人信号 | 无 | 短评（≤10 字）−1.5；表情短评（≤40 字）−1.0 | 真人短评 + 表情包是强人味 |

## 三、结果

| 组 | bot | unsure | human |
|---|---|---|---|
| DSH 圈 565 | 154 | 127 | 284 |
| 热门区 1,140 | **1** | 41 | 1,098 |

- **热门区误伤率 = 1/1,140 ≈ 0.09%**，唯一那条是 `账号已注销` 的账号（本来也不该回）。
- 热门区 1,098 条判 human，抽 30 条逐条看，**全是真人**（观后感、剧情猜测、`[哦呼]`、`蹲蹲`）。
- DSH 圈里判 human 的 284 条，抽 30 条人工标注：**27 真 / 3 假**（3 条是 Lv4–6 的老号在模仿真人写作）。

## 四、人工标注样本的成绩

标注方式：从两个「human」桶各取前 30 条逐条读（`labels_sample.json`，待本人复核）。

```
n=60   TP=57  FP=3  FN=0
「回真人」精确率 = 95.0%    召回率 = 100%（本样本）
```

**3 条漏放的 bot**（都会被回复，是真风险）：

| 账号 | 评论 | 为何漏 |
|---|---|---|
| 人鱼·鱼 Lv6 | `@人鱼·鱼 二十多个开关收进一个设置页…这个面板思路可以直接抄🫧` | 有装扮、自 @ 自己、句子太规整但带 emoji |
| dee·ol Lv4 | `@青山·山 超可爱贪吃大肥鱼按语境就是向量检索…` | 人设词藏在句子里，不带「主人」句式 |
| dee·ol Lv4 | `@青山·山 封天万里的大肥鱼别抢了…` | 同上，且同一号连续两条 |

**关键**：这 3 条**全部**被 `needs_llm` 标记命中（长句 + @ + 无表情）。也就是说「规则初筛 + LLM 只复核标记项」这条路线，能把这类漏放的 bot 兜住。

## 五、现在能拍板的结论

1. **规则初筛在真人密集区几乎不误伤**（0.09%），可以直接用来挡掉大部分 bot，省 token。
2. **DSH 这种 bot 密集区仍有约 10% 的「老号伪装」会漏**，单靠账号画像 + 文本规则解决不了，必须让 LLM 看一眼。
3. 建议最终策略：
   `bot / unsure → 不回`（已被吃掉 281 条）
   `human 且 needs_llm → 送 LLM 判一次`（238 条，成本可控）
   `human 且非 needs_llm → 直接回`（1,187 条）
4. 人工标注样本只有 60 条，**95% 是这 60 条的精确率，不是全站准确率**；下一步要把标注扩到 300+ 条再定阈值。
